কেন GitHub Actions প্রয়োজন?
iptv-org/iptv এর মূল লিস্টে ৫০,০০০+ চ্যানেল থাকে। সরাসরি ব্রাউজারে সব লিংক চেক করলে CORS ও স্পিডের কারণে ব্রাউজার ক্র্যাশ করবে। তাই ব্যাকএন্ডে একটি স্ক্রিপ্ট স্বয়ংক্রিয়ভাবে প্রতিদিন লিংক যাচাই করে একটিভ চ্যানেলের channels.json তৈরি করে।

GitHub Action সেটআপ করার ৩টি সহজ ধাপ:
  1. আপনার GitHub রিপোজিটরিতে .github/workflows/update.yml ফাইল তৈরি করুন।
  2. পাইথন স্ক্রিপ্ট প্রতিদিন নির্ধারিত সময়ে লাইভ M3U ডাউনলোড ও মাল্টিথ্রেডিং দিয়ে পিং করবে।
  3. যেসব চ্যানেল HTTP 200 রেসপন্স দেয়, শুধু সেগুলো দিয়ে channels.json অটো-কমিট করে দেবে।
